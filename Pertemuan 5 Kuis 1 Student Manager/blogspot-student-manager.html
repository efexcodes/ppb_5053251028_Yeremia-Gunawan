1. Deskripsi Studi Kasus

Staf administrasi program studi biasanya mencatat data mahasiswa secara manual di buku atau spreadsheet. Cara ini lambat dan mudah salah: NIM bisa ganda, data lama sulit dicari, dan perbaikan atau penghapusan data tidak tercatat dengan rapi.

Student Manager adalah aplikasi Android sederhana untuk mengelola data mahasiswa langsung dari ponsel. Pengguna dapat melihat daftar mahasiswa, menambah data baru, mengubah data yang salah, menghapus data yang tidak berlaku, dan mencari mahasiswa tertentu dengan cepat.

Data Mahasiswa

Atribut Aturan
NIM Wajib diisi, hanya angka, dan harus unik
Nama Wajib diisi
Program Studi Wajib dipilih: Informatika, Sistem Informasi, Teknik Komputer, Desain Komunikasi Visual, Manajemen, Akuntansi

2. Fitur Aplikasi

No Fitur Penjelasan
1 Splash Screen Tampilan awal selama ±1,5 detik berisi logo dan nama aplikasi.
2 Daftar Mahasiswa Layar utama berisi kartu mahasiswa (avatar, nama, NIM, program studi) dan teks "Jumlah mahasiswa: N".
3 Pencarian Menyaring daftar secara langsung saat mengetik, berdasarkan nama, NIM, atau program studi. Ada tombol × untuk menghapus kata kunci.
4 Tambah Mahasiswa Tombol + (bulat, biru) membuka form NIM, Nama, dan dropdown Program Studi, dengan tombol Batal dan Simpan.
5 Edit Mahasiswa Ikon pensil membuka form yang sudah terisi data lama.
6 Hapus Mahasiswa Ikon tempat sampah membuka dialog konfirmasi "Hapus Mahasiswa?" sebelum data dihapus.
7 Empty State Muncul "Belum ada data mahasiswa" saat daftar kosong, atau "Mahasiswa tidak ditemukan" saat pencarian tanpa hasil.
8 Menu ⋮ Refresh (mengosongkan pencarian), Tentang Aplikasi, dan Keluar.
9 Validasi Input Pesan kesalahan bila kolom kosong, NIM bukan angka, atau NIM sudah terdaftar. (tambahan)
10 Umpan Balik Snackbar setelah tambah, ubah, dan hapus data. (tambahan)

3. Alur Navigasi

Splash → Daftar Mahasiswa ── Cari (filter di layar yang sama)
                          ├─ Tambah → Simpan / Batal → Daftar
                          ├─ Edit   → Simpan / Batal → Daftar
                          ├─ Hapus  → Dialog konfirmasi → Daftar
                          └─ Menu ⋮ → Refresh / Tentang / Keluar

4. Teknologi

  • Kotlin sebagai bahasa pemrograman
  • Jetpack Compose untuk membangun antarmuka
  • Material 3 sebagai sistem desain
  • Android ViewModel untuk menyimpan state agar tidak hilang saat layar diputar

Data disimpan di memori, dimulai dari tiga data contoh (Budi Santoso, Siti Aminah, Andi Wijaya) seperti pada wireframe. Data kembali ke data contoh setelah aplikasi ditutup sepenuhnya.

7. Keterbatasan dan Pengembangan Lanjutan

  • Data belum tersimpan permanen; dapat dikembangkan dengan Room atau DataStore.
  • Teks antarmuka masih ditulis langsung di kode; dapat dipindahkan ke strings.xml untuk mendukung multibahasa.
  • Menu Refresh saat ini hanya mengosongkan pencarian karena belum ada sumber data eksternal.
